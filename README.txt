SPARTANS CRICKET CLUB - WEBSITE PACKAGE (GitHub Pages)
Live at: https://www.spartanscricketclub.us

Contents
  index.html   the whole website
  assets/      photos, videos, logos and the link preview image (og-image.jpg)
  CNAME        keeps your custom domain connected. Never delete it.

Updating the live site
  1. Unzip this package.
  2. GitHub > spartans-cricket-club-website > Add file > Upload files.
  3. Drag in index.html, CNAME and the assets folder. Commit changes.
  4. Live in 1-2 minutes.

Visitor stats (Cloudflare Web Analytics)
  Get your token from Cloudflare (Analytics & Logs > Web Analytics > Add a site),
  then in GitHub open index.html > pencil (Edit), find  window.CF_WA_TOKEN=''
  and paste the token between the quotes. Commit changes.
